# Student Management System Using Stream API

## Project Description

This is a Java-based Student Management System that allows users to register students, manage student records, search and filter students, and analyze academic performance.

The project uses Java Collections, Object-Oriented Programming (OOP), and the Java Stream API to manage and process student information.

## Features

* Register new students
* Display all registered students
* Search students by ID or name
* Prevent duplicate student IDs
* Filter passing and failing students
* Sort students by name and average marks
* Display all courses and unique courses
* Search students by course
* Display unique student skills
* Group students by course
* Generate student performance reports
* Identify the top-performing student
* Display the top three students
* Apply bonus marks and display final rankings

## Technologies Used

* Java
* Java Collections Framework
* Java Stream API
* Object-Oriented Programming (OOP)
* Visual Studio Code

## Project Structure

* `Main.java` — Runs the application and displays the menu.
* `Student.java` — Represents a student and stores student information.
* `StudentManager.java` — Manages student records and implements the system's operations.

## How to Run

1. Install the Java Development Kit (JDK).
2. Open the project folder in Visual Studio Code.
3. Ensure the Java files are in the correct package or folder.
4. Run `Main.java`.
5. Follow the menu instructions displayed in the terminal.
